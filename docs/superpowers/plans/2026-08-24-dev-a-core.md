### Task A9: `receive()` orchestration (public entrypoint)

**Files:** Create `packages/core/src/receive.ts`; Test `packages/core/test/receive.test.ts`
**Interfaces:** Produces `receive()` used by `createAnchorCCTP`. (H5: B3/B7 consume events + result.)
`ReceiveParams = { sourceDomain: number; burnTxHash: string; destinationAddress: string; dustCollectorAddress?: string; pollIntervalMs?; maxRetries? }`.
`ReceiveResult = { amount: bigint; dust: bigint; txHash: string; settled: boolean }`.

- [ ] **Step 1: Write failing test** (full flow, injected mocks via `_test`)
```ts
import { createAnchorCCTP } from '../src/config.js';
import { ReplayTransferError, InvalidDomainError } from '../src/errors/index.js';
function makeSdk(over: any = {}) {
  return createAnchorCCTP({
    signer: async (x) => 'SIGNED', dustCollectorAddress: 'G'.repeat(56),
    _test: { attestation: async () => ({ status: 'complete', attestation: '0xa', message: '0xm', signature: '0xs' }), ...over },
  } as any);
}
test('receive() polls, converts, credits, emits onSettled', async () => {
  const sdk = makeSdk(); const settled: any[] = [];
  sdk.on('onSettled', (p) => settled.push(p));
  const r = await sdk.receive({ sourceDomain: 0, burnTxHash: '0x1', destinationAddress: 'G'.repeat(56) });
  expect(r.settled).toBe(true); expect(settled[0].amount).toBeGreaterThan(0n);
});
test('replay of same burnTxHash throws ReplayTransferError', async () => {
  const sdk = makeSdk();
  await sdk.receive({ sourceDomain: 0, burnTxHash: '0xreplay', destinationAddress: 'G'.repeat(56) });
  await expect(sdk.receive({ sourceDomain: 0, burnTxHash: '0xreplay', destinationAddress: 'G'.repeat(56) }))
    .rejects.toMatchObject({ code: 'REPLAY_TRANSFER' });
});
test('unknown sourceDomain throws InvalidDomainError before credit', async () => {
  const sdk = makeSdk();
  await expect(sdk.receive({ sourceDomain: 999, burnTxHash: '0x2', destinationAddress: 'G'.repeat(56) }))
    .rejects.toMatchObject({ code: 'INVALID_DOMAIN' });
});
```
- [ ] **Step 2: Run → FAIL.**
- [ ] **Step 3: Implement** — `receive()` sequence (PRD §5.1 + invariants):
  1. `assertSupportedDomain(sourceDomain)` (reject unknown first).
  2. `replayStore.isProcessed(burnTxHash)` → if processed, throw `ReplayTransferError` (or return existing record).
  3. Poll attestation; emit `onReceiving` each poll. Timeout → `AttestationTimeoutError`.
  4. `verifyAttestation` — unverified ⇒ do NOT credit, throw.
  5. `submitMint` via forwarder + signer; failure → `MintFailedError`.
  6. `convert6to7(amount)` → stellar 7-decimal + dust.
  7. `ensureTrustline` (opt-in guard).
  8. Credit destination; route dust to `dustCollectorAddress`; emit `onSettled`, `onDustCollected` if dust>0.
  9. `replayStore.markProcessed`.
- [ ] **Step 4: Run → PASS (full core coverage ≥90%).**
- [ ] **Step 5: Commit** — `git commit -m "feat(core): receive() orchestration with full security invariants"`
